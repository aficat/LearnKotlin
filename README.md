# LearnKotlin

A simple educational Android mobile application that helps anyone learn Kotlin.

## About  
This project is an Android app designed to provide interactive learning of the Kotlin programming language. It is ideal for beginners who wish to get started with Kotlin in a mobile-first environment.

## Features  
- Core Kotlin concepts explained in an Android UI  
- Hands-on examples you can run and explore  
- Designed for readability and ease of use  
- Open source, easy to extend or customise  

## Why this project?  
Kotlin is now a first-class language for Android development and is increasingly used for other platforms too. By offering a dedicated learning app, we aim to:  
- Lower the barrier for beginners in Kotlin  
- Provide a consistent, mobile-friendly learning experience  
- Encourage experimentation and customisation  

## How to Use  
1. Clone the repository  
2. Open in Android Studio or IntelliJ IDEA  
3. Build and run the app on your device or emulator  
4. Explore the modules, examples and activities  
5. Modify or extend the examples to deepen your understanding
